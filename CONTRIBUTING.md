# How to contribute

At first create an issue in the [issue tracker](https://git.thulb.uni-jena.de/thulb/thunibib/-/work_items/new?type=Issue&initialCreationContext=list-route). If you have a service desk ticket use its title as title for the issue otherwise choose a proper title by yourself

## Branch naming convention
```
<GITLAB ISSUE-ID>-[<JIRA-TICKET-ID>-]<GITLAB ISSUE TITLE> 
```
